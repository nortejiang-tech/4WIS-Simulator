# 驾驶体验迭代 v0.100.0 — 落地方案

基于 `docs/driving_experience_plan.md`，已核对基线 `710720d` 的全部插入点。三项决策已确认：方向意图踏板模型（W/S 是方向意图，停住后松开重按切倒车）、空格=手刹、方向盘默认 540°。执行顺序 C→A→B（B 内部先做 B3 解耦再改映射）。

## 总体设计决策

### 踏板语义分层（核心架构决策）
采用**前端方向意图状态机 + 后端纯物理语义**分层：

- **后端 `DriverInput`**（纯物理）：`throttle∈[0,1]`(驱动) + `brake∈[0,1]`(摩擦制动踏板) + `gear∈{-1,0,1}`(R/N/D) + `steering` + `handbrake`。符合文档 A1 设计。
- **前端**：新建共享 driver-intent 解析层（一个 hook `useDriverIntent`），键盘 W/S/空格、手柄 LT/RT、方向盘踏板统一汇入，内部维护方向状态机（FORWARD/REVERSE + stopped-armed 标志），输出 `(throttle, brake, gear)` 经 ws 发后端。这样"策略也用在手柄和方向盘上"天然成立。

方向状态机规则（实现 `useDriverIntent`）：
```
FORWARD 态:  W→throttle↑(gear=D)  S→brake↑    停住(|v|<0.3)且S松开后再按S → 切REVERSE
REVERSE 态:  S→throttle↑(gear=R)  W→brake↑    停住且W松开后再按W → 切FORWARD
停住时按住的制动键不自动切换方向（符合"松开重按"）
```

### 向后兼容
- 后端 `set_driver` 收到旧协议 `throttle<0` 且无 `brake` 时，转换为 `brake=-throttle, throttle=0`（兼容旧脚本 `brake` 动作 = `throttle=-1`）。
- `throttle` 作为 `forward-backward` 的只读派生属性保留，供 user_python 脚本读取。
- `script.py:_brake` 改为直接发 `brake=1.0`。

## 工作包 A — 制动系统

### A1. 数据模型 `core/state.py`
`DriverInput` 改为：`throttle∈[0,1]` + 新增 `brake∈[0,1]` + `gear:int=1`({-1:R,0:N,1:D}) + `steering` + `handbrake` + `mode_params`。`throttle` 加只读 property `throttle_signed = forward - backward` 兼容旧脚本读取。

`VehicleParams`（frozen，加默认字段）新增：`brake_torque_max=12000.0`、`brake_bias_front=0.65`、`brake_tau=0.08`、`v_max_reverse=5.0`。

### A2. 协议与落地
- `api/ws.py:_apply_client_message` 透传 `brake`/`gear`。
- `core/simulator.py:set_driver` 加 `brake`/`gear` 参数 + 区间钳制 + 向后兼容（`throttle<0` 且无 brake → 转换）。
- `input/script.py:_brake` 改发 `brake=1.0`，`action_schema.py` 文档串更新。

### A3. 第 1 层 — 纵向驾驶员模型
新建 `controller/longitudinal.py`：`speed_command(params, driver, v_actual, dt) -> v_cmd`。把 9 处策略里的 `v_cmd = p.v_max * float(driver.throttle)` 统一替换（涉及 ideal_ackermann/ackermann/rear_wheel_steer/crab/zero_radius/fault_reconfig/follow_trajectory/manual_wheel/manual_body 等）。逻辑：
- gear=1(D): `v_target = throttle · v_max`，brake 时朝 0 收敛（减速率上限 `a_brake_max = brake · μ_eff · g`）
- gear=-1(R): `v_target = -throttle · v_max_reverse`
- gear=0(N): 仅滑行阻力
建议收进 `controller/base.py` 共享 helper。

### A4. 第 2 层 — 摩擦制动扭矩（dynamic/multibody）
- `vehicle/dynamic.py:143` `t_motor` 改为 `t_motor + t_brake`，其中 `t_brake_i = -sign(omega_i) · brake_filtered · brake_torque_max · bias_i/2`（前轮 bias=0.65，后轮 0.35）。brake 经 `brake_tau` 一阶滤波。
- `vehicle/model_core.py:semi_implicit_wheel_spin` 加零穿越钳制：`w_trial·omega_i < 0` 且制动主导时 `w=0`（防反向抖振）。
- `vehicle/wheel_servo.py` 加门控：`brake>0.02` 时伺服输出钳到 `min(t,0)` 且冻结积分器（防伺服与制动打架）。
- 抱死是特性：`T_i > r·μ·Fz_i` 时轮子锁定，`VehicleState` 加 `wheel_locked: np.ndarray[bool]` 推前端 HUD。

### A5. 倒车与驻车
- 倒车：前端方向状态机输出 `gear=-1`，后端 `v_max_reverse=5.0` 限速。
- 驻车：`handbrake=1` 时后轴施加 `brake_torque_max·(1-bias)` 固定制动扭矩。空格键触发。

### A6. 前端
- 新建 `useDriverIntent` hook（方向状态机，汇合键盘/手柄/方向盘）。
- `KeyboardInput.tsx`：W/S 走 intent，空格=handbrake，移除"松油门"语义。
- `gamepadConfig.ts`：踏板值汇入 intent hook（不再单独算 throttle）。
- `api/ws.ts` 的 `setDriver` 签名加 `brake`/`gear`/`handbrake`。
- HUD 显示档位(D/N/R)、brake 踏板、handbrake、轮速抱死状态。

### A7. 测试 `backend/tests/test_brake.py`
不倒车、制动距离随 μ 放大、前轴先抱死、抱失去侧向力、伺服不打架、运动学有率限制动、旧 throttle<0 兼容。

## 工作包 B — 转向映射（先做 B3 解耦）

### B3. 实验单位解耦（前置，此时 golden 不会变红）
- `experiment/schema.py` 的 `SteerProfile` 加 `unit: Literal["normalized","front_deg"]="normalized"`。
- `experiment/session.py:137` 注入逻辑：`unit=="front_deg"` 时把 amplitude 当前轮角度[deg]，转弧度后直接设 `driver.steering` 绕过手感层（或直接构造 delta_cmd）。
- 两个 golden 实验 yaml 改为 `unit: front_deg`，amplitude 换算：step_steer 0.05→3.57°，dlc 0.06→4.28°（基于 κ_max=0.3291, L=3.16: δ=atan(κ·L)）。注意核对真实 yaml（step_steer 实际 0.05 非 0.06）。
- 此步先**不** promote 基线（单位换了但手感没改，KPI 不变）。

### B1. 三层映射 `controller/steering_feel.py`
```
θ_sw = steering · (steer_wheel_range/2)
δ_raw = θ_sw / i(v)     i(v) = i_low + (i_high-i_low)·v²/(v²+v_ref²)
δ_eff = δ_raw · s(v,μ)  软限幅保证 a_y ≤ steer_ay_ref_frac·μ·g
```
`VehicleParams` 新增：`steer_wheel_range=540.0`、`steer_ratio_low=4.0`、`steer_ratio_high=14.0`、`steer_ratio_v_ref=22.0`、`steer_ay_ref_frac=0.9`。

### B2. 策略衔接
`ideal_ackermann`：`κ_cmd = tan(δ_eff)/L` 再走原 ICR 构造，保持零侧滑语义。注意 `_kappa_max` 缓存改为 compute 内实时算（软限幅改了有效 κ）。`rear_wheel_steer`：steering→δ_eff 前轮角。`crab`/`zero_radius` 不走此链路（注释写明理由）。

### B3b. 改完映射后重新 promote golden 基线
手感改了，KPI 会变。`python scripts/check_golden_experiments.py --update` 重生成 `docs/golden_experiments.json`，在 `docs/golden_baseline_changelog.md` 记账（原因=手感重映射+单位解耦，附换算关系）。

### B4. 前端
- `parameterGroups.ts` 暴露 `steer_wheel_range`/`steer_ratio_low`/`steer_ratio_high`（核心转向组）。
- 手柄面板加"方向盘总转角"输入，一键切 270°（Dolio R270）。
- HUD 增 θ_sw 与当前 i(v) 读数；后端状态帧加 `steer_wheel_angle_deg`/`steer_ratio_current`。

### B5. 测试 `backend/tests/test_steering_feel.py`
低速满舵=几何极限、高速满舵在 0.9μg±15%、传动比单调随速、软限幅随 μ、运动学↔动力学横摆增益收敛到 2× 内。
