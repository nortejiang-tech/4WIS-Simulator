# v0.105.0 动力学与数值修订复核

基线：v0.104.0 / d810968e0e3f0ce407b37e5fc8b92b09f6e661c3。日期：2026-11-13。

## 发现与处置

1. 原实验的机械卡滞锁存轮胎总角，再作为执行器目标输入，既叠加一次前束，又保留了正常伺服滞后。新实现锁存机构坐标并旁路伺服；真实轮角仍含静态前束和 K&C。
2. 原自由脚轮每次激活角速度置零，显式摩擦求解再经过正常电机滞后。新实现继承机构角速度，按主销回正负载求解独立转向自由度；隐式阻尼和集合值库仑摩擦形成静止区，机械止挡吸收向外动能。
3. 实时、实验、Agent 原来故障处理不一致；传感器随机数随状态查询次数变化。新内核统一时间线，观测只随接受的积分子步采样；查询无随机副作用。
4. 组合体/轮速/转向为分区耦合，整体不是四阶方法。原外层 5 ms 在 14 s 多故障样例中相对 0.625 ms 的最大位置差约 0.60 m，未满足本例预设 0.15 m 门槛。改为动力学内部最大 1.25 ms，保留外层控制、记录节拍；修订前后数据分别在 `before_substeps.json` 与 `summary.json`。
5. 子步初版把整帧转向输入斜坡压缩到了第一个子步，中心区迟滞由约 0.302 增至 0.860 N·m。此错误已修正：按整个外层周期插值，再施加故障；额外事件切步也维持恒定输入斜率。机械/角控制内层取 ceil 分步，确保不超过声明步长。

## 验证证据与残余敏感性

- `test_physics_audit_v105.py`：两种动力学、随机非中心质心与已知外力的 Newton–Euler 平衡；支承总和与未饱和俯仰/侧倾力矩；两种轮胎共 200 组摩擦圆和隐式轮速角冲量；含非网格故障边界的完整转向斜坡验证。
- `test_multipoint_faults.py`：8 类 × 4 轮 × 2 模型，加上时间边界、恢复、冲突、静摩擦/耗散/止挡、前束、观测组合、宿主一致性、Agent 幂等及 REST 原子拒绝。
- 多故障样例的 12 组外层步长比较均满足本例预设门槛，详见样例报告。此数值门槛不等同车辆安全门槛。
- `steering_convergence.json`：中心区 5 ms 与 0.625 ms 比较，力矩梯度 9.57792 / 9.58046 N·m/g，迟滞 0.30128 / 0.30326 N·m，死区 0.39553 / 0.40246°，横摆相位 1.86066 / 1.98211°。相位残差 0.12145°，不可将黄金比较容差解读成物理精度。控制输入仍是外层采样的，研究更小相位差时需降低外层 dt 并重复收敛分析。
- 重现：`python scripts/analyze_multipoint_faults.py` 与 `python scripts/audit_steering_substeps.py`（安装 backend[dev]）。
- 补充无故障控制工况：`control_convergence.json` 与 `python scripts/audit_steering_substeps.py --controls-only`。新版默认步长的阶跃速度 RMS 为 0.24293 km/h，0.625 ms 参考为 0.26274；移线分别为 0.15197 / 0.16732 km/h。相较旧版 0.13444 / 0.08227，默认新版更接近细步长解。两工况的所有已列 KPI 与细步长的差异均在原黄金容差内，未以放宽阈值掩盖离散误差。

## 黄金数据迁移

`golden_migration.json` 列出超出旧容差的全部 6 项。无故障阶跃/移线速度 RMS、阶跃超调和中心区相位随更细的车轮/车体耦合改变；自由转向横摆峰值/残余随伺服旁路、初始角速度与摩擦求解改变。更细积分不保证每个控制性能指标都变好，例如阶跃速度 RMS 从 0.13444 增至 0.24293 km/h，应按新版重审设计目标。

黄金值通过同一正式研究/实验入口重新生成；所有容差、样本数和原有故障分类保持。旧标签保留旧数据。新黄金验证的是未来回归稳定性；独立物理断言、收敛试验才是本次迁移的依据，不以重写黄金本身作为正确性证明。

## 适用边界

这是降阶独立轮端机构模型，忽略转向惯量对车体的反作用、完整三维主销投影与高频摆振；共享齿条的独立轮端卡滞组合拒绝运行。传感器故障仅影响观测，不进控制器反馈。支承饱和不是翻滚预测。台架、实车、机构参数标定与独立外部求解器相关性均为 PENDING；本轮不连接物理车辆或 CAN。
