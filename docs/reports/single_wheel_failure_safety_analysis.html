四轮独立转向系统单轮转向失效的 ISO 26262 功能安全可控性分析
与容错控制策略设计

仿真平台：4WIS Simulator v0.12.0（实验底座 SimSession · 定时故障注入 · fault_reconfig 降级策略）· 车辆：LS9 默认参数（m=2900 kg，L=3.16 m）· 模型：simplified_dynamic（RK4 + 半隐式轮速 + Fz 敏感线性胎）· 复现：python scripts/study_single_wheel_failure.py

摘要 — 四轮独立转向（4WIS）以四个独立转向执行器换取了低速灵活性与高速稳定性，但也引入了传统转向系统不存在的失效模式： 单轮转向执行器卡死。本文在 ISO 26262 概念阶段框架下，对单个前轮或后轮转向卡死（带角卡死 / 回中卡死 / 原角冻结） 开展定量可控性（Controllability）分析：以无故障参考轨迹的横向偏差、车道脱离时间（TTLD）、横摆扰动峰值等指标， 在高速直行、稳态弯、双移线三种代表工况 × 前/后轮 × 6 个失效组合上进行数值仿真（开环无驾驶员纠正，代表最不利暴露）。 结果表明：未缓解时高速直行组合为 C3（100 km/h 直行 FL 卡死 +4°：2 s 航向漂移 15.2°、TTLD 仅 0.8 s；后轮卡死更演化为 25°/s 量级的自旋趋势）， 弯中与双移线组合为 C2。针对性设计了三层安全机制：残差检测（SM1）、同轴镜像力抵消 + ESP 级横摆 PI 稳定 （SM2，利用 4WIS 冗余转向自由度，将卡死轮的寄生侧向力与横摆力矩在同轴上精确对消，PI 环压制饱和残差）、 带减速度限幅的降级限速（SM3）。缓解后全矩阵消灭 C3：高速直行 C3→C2（2 s 航向漂移降至 0.7°、横摆扰动峰值降 ~70%），后轮自旋工况被完全镇定（Δr 峰值 31.8→3.7°/s）。 检测延时敏感性给出 FTTI 分解依据：τ_d ≤ 0.05 s 时达 C1，τ_d ≤ 0.3 s 保持 C2 且反应窗内偏差 < 0.9 m 裕度。 文中同时报告了被否决的纯运动学 ICR 重构方案的对比数据，说明其蟹行漂移特性不适于在险工况。

关键词：四轮独立转向；ISO 26262；可控性；容错控制；控制再分配；卡死失效；HARA

1　引言

4WIS 底盘为每个车轮配备独立转向执行器（本文对象为分体齿条 + 无刷电机构型），在带来最小转弯直径、 高速斜行/零侧偏等能力的同时，执行器数量翻倍使转向系统失效率相应上升，且出现了传统机械转向不存在的 非对称失效形态——单轮卡死时其余三轮仍完全可控。这既是风险（非对称侧向力直接产生横摆），也是机会 （剩余三个转向自由度构成天然的控制重构冗余——传统前转向车辆的后轴故障无任何执行器可用于补偿）。 本文的目标有三：①在 ISO 26262-3 概念阶段框架下量化"单轮卡死"危害事件的可控性 C；②设计并验证利用 4WIS 冗余的安全机制；③给出检测延时预算（FTTI 分解）的仿真依据。

2　相关项定义与失效模式

2.1 相关项（Item）

四轮独立转向系统：转向指令由控制策略（理想阿克曼分配）计算，每轮经"电机-减速器-齿条-拉杆"链执行； 执行器带一阶滞后（τ=60 ms）与角速率限幅（8 rad/s）。轮速由每轮轮毂电机速度伺服（PI+指令前馈）维持。

2.2 分析的失效模式（FMEA 摘要）

编号失效模式典型成因本文注入方式研究工况
FM1带角卡死（stuck-at-value）齿条机械卡滞/异物、电机失步后抱死 t_f 起 δ_cmd≡+4°，经执行器动力学生效高速直行
FM2回中卡死（stuck-at-zero）控制器复位至默认位后失效、回正弹簧构型故障 t_f 起 δ_cmd≡0稳态弯（弯中丢转向）
FM3原角冻结（stuck-hold）供电/驱动级失效，电机自锁力矩保持当前角 t_f 起冻结实测轮角双移线（紧急变道中）

失控甩摆（runaway）与完全松脱（free-wheeling）不在本文范围（前者由驱动级硬件互锁处置，后者需机械设计兜底）， 在 §7 讨论。

3　HARA：危害分析与风险评估

危害事件 H1：单轮转向卡死导致非预期横摆/侧向运动，车辆脱离车道。S/E 按工况判定， C 由 §4–§6 的定量仿真支撑（这正是本文方法与常规定性 HARA 的差别）。

运行场景S（严重度）E（暴露率）C（未缓解，本文仿真）ASIL
高速公路直行 ~100 km/h，对向/邻道有车S3（高速偏离车道/对撞）E4（高速巡航常见） C3（TTLD 0.8 s < 反应时间）D
山区/匝道稳态弯 ~60 km/hS3（弯中失稳驶出路外）E3 C2（回中卡死→缓慢转向不足外漂）B
紧急变道（双移线）~60 km/hS2–S3E2（紧急机动少见） C2A–B

由此导出安全目标 SG1：单个转向执行器失效不得导致车辆非预期偏离车道（ASIL D）， 安全状态：受控降级行驶（限速 + 重构转向）直至安全停车。

4.2 指标定义

以同工况无故障参考 run 的轨迹为基准折线，度量：横向偏差 d(t)（点到参考折线最小距离）； 车道脱离时间 TTLD = min{t: d(t) > 0.9 m}（3.75 m 车道 − 1.96 m 车宽 → 单侧裕度 0.9 m）； 横摆扰动 Δr(t) = r − r̄pre 峰值与 4 s 残余；侧向加速度增量峰值 |Δa_y|（与无故障参考时间对齐相减，稳态弯的名义 a_y 不计入）；质心侧偏角峰值；2 s 航向漂移。

4.3 可控性分级判据

参照 ISO 26262-3 C 定义与驾驶员反应时间工程惯用值（感知-反应 ≈1.2 s，95 分位）：

等级判据（评估窗 5 s）含义
C1TTLD=∞ 且 d_max<0.45 m 且 Δr 残余<1°/s 且 Δa_y峰值<2 m/s² 车辆自持车道内，≥99% 驾驶员无需紧急干预
C2TTLD ≥ 1.2 s 且 Δa_y峰值 < 5 m/s² 反应窗内未脱离车道，一般驾驶员可纠正
C3其余（反应窗内已脱离车道或强横摆）难以控制

5.1 三层安全机制

机制内容实现层
SM1 检测每轮 |δ_cmd − δ_meas| 残差监控 + 去抖（本文合并为检测延时 τ_d，基线 0.15 s； §6.3 给出 τ_d 预算依据）轮端 MCU + 域控裁决

5.2 SM2：同轴镜像力抵消（核心机制推导）

设轮 i 卡死于 δ_s，其相对正常分配角的偏差 e = δ_s − δ_ialloc。线性胎区内该轮注入寄生侧向力 ΔF_y ≈ −c_α·e 与横摆力矩 x_i·ΔF_y。同轴伙伴轮与卡死轮共享同一纵向力臂 x，故令

δ_partner = δ_partneralloc − (δ_s − δ_ialloc)

即可同时精确对消 ΣF_y 与 ΣM_z（图 1b）。驾驶员的曲率请求继续叠加在三个健康轮的正常分配上—— 转向功能对驾驶员透明地保留。鲁棒性由横摆率反馈补偿非线性残差（载荷转移、c_α(F_z)、饱和）：

δ_fb = k_r·(r_des − r)，健康前轮 +δ_fb，两后轮 −δ_fb/2（力矩配平分配），k_r = 0.12

5.3 被否决方案：纯运动学 ICR 重构（设计权衡记录）

另一直观方案是把期望瞬心投影到卡死轮的转向约束线上、其余三轮对准投影点——四轮纯滚动无搔刮。 实测（同 §6.1 工况）：该方案过渡瞬态横摆峰值达 22°/s（未缓解基线仅 8°/s），航向永久偏转 23.5°， 且"直行请求"退化为 ≈δ_s 的蟹行漂移（5 s 侧向漂 31 m）。原因：卡死角非零时约束线上不存在 "直行"解，最近投影解是蟹行；瞬态中三轮大角度重定向本身激发横摆。故该方案不适于在险接管， 仅保留为静态/蠕行回家模式（轮胎零搔刮、发热最小）。此教训说明：失效后控制目标应是"保持航向/路径" （力平衡），而非"保持运动学一致"（零搔刮）。

6.4 缓解的代价与限速依据

镜像抵消让前轴两轮以 ≈±4° 侧偏角持续对抗：单轮侧向力 ≈ c_α·4° ≈ 8 kN 量级、接近 μF_z 饱和， 轮胎发热/磨损增加，且该轴向外侧机动的侧向力储备被显著占用——这是 SM3 限速 60 km/h 的直接依据 （限速后 a_y 需求下降、载荷转移减小，保留足够摩擦椭圆裕度给横摆反馈项）。

7　讨论与局限

① 本文为开环最不利口径：真实驾驶员会介入，C 分级偏保守（安全侧）。② 线性胎+摩擦圆在 4° 卡死角 （接近饱和）区段低估过渡非线性，建议后续用 Pacejka 通道复跑（平台参数 tire_model=pacejka 一键切换）。 ③ 执行器模型为一阶滞后+速率限幅，未含力矩饱和/供电失效耦合——镜像轮所需保持力矩（≈齿条力×臂长） 需在执行器选型中按 §6.4 的持续侧偏工况校核（负载特性页可直接给出该工况齿条力）。④ runaway 模式需 硬件级互锁（驱动桥臂断开→退化为 FM3 原角冻结，即回到本文已覆盖的场景）。⑤ 双移线中段冻结的 C2 结果 提示：机动中失效的最优策略可能需要前馈"完成当前机动再降级"，留作后续。

8　结论

(1) 建立了"定时故障注入 + 无故障参考轨迹偏差 + TTLD"的可控性定量评估流水线，可复现、可扩展至任意 失效×工况矩阵。(2) 未缓解的单轮卡死在高速直行与弯中均为 C3，确立 SG1 为 ASIL D。(3) 提出的"同轴镜像力抵消 + 横摆 PI 稳定 + 限幅减速"降级控制利用 4WIS 独有冗余，将全矩阵 C3 清零 （高速直行 C3→C2，快检测下 C1）；其中后轮高速卡死的自旋趋势（传统车辆无从补偿的失效位置）被完全镇定。 机制解析（同轴等臂 → 力/矩同时对消）、实现简洁（一行重分配 + 横摆 PI）、对驾驶员透明。(4) 给出 FTTI 分解建议（检测 ≤250 ms，总预算 ≈1 s）。 (5) 记录了纯运动学重构方案的失败数据，提炼出"失效后控制目标 = 路径保持而非运动学一致"的设计原则。
