## 2. 测试分层方法

按 V 模型组织，与仓库既有门禁体系一一对应：

```
需求/功能层  ── Playwright e2e（52 项，真实后端 + 生产构建）＋ pre_release 门禁
     │
集成层       ── smoke（32 项）、黄金实验回归（5 项）、reference benchmark（2 项）、
     │         v2 专项（转向/study/targets 279 项）
     │
单元层       ── 后端 pytest（777 项，55 文件）、前端 tsc --noEmit
     │
物理基础     ── 解析闭式解对照（steady circle / step steer）、不变量测试、
                偏差钉住测试（把"已知缺陷"变成可断言的测试）
```

设计要点（来自仓库文档与测试本体）：

- **"默认关闭则逐位不变"是转向被控对象层的底线契约**：`test_disabled_plant_changes_nothing` 断言的是 `off == again`（位级相等）而非 `pytest.approx`（`test_steering_integration.py:54`）。本层开启后整车行为允许 `rel=0.03` 偏差（同一文件 :84）。
- **已知缺陷被钉成测试**：仓库明确采用"先钉住缺陷、后修复、修复时删除测试"的做法（见 `test_study_e2e.py:153` 的 docstring："When the analytic path is fixed, delete this test"）。
- **覆盖不足必须显式报告**：目标层把"未评估"作为一等输出，不存在"没测到但显示通过"的路径。

## 6. 物理与数学正确性核查

### 6.1 运动学与理想阿克曼
- 四轮瞬心严格共点（smoke 不变量）；圆周积分闭合；解析稳态圆周/阶跃对照偏差在 1e-7 dps 量级（§4.3）。
- 软限位与握持参考（grip reference）：全锁可达、最小转弯半径保持、冰面限位收紧、手感在方向盘换装（270°/540°/900°）下不变——转向"手感量"对传动系统参数的不变性有测试钉住。

### 6.2 轮胎模型
- Pacejka 侧滑回归（smoke）、`μ(Fz)` 载荷敏感（摩擦圆利用率曾报 1.10 的缺陷已修，现在在 RK4 力路径的每个阶段载荷上生效，四个消费方口径一致）、`c_alpha(Fz)` 指数模型 + 轴侧偏分配系数（默认 0.80 前 / 1.20 后）。
- **边界**：`c_alpha(Fz)` 指数形式来自工程假设，缺同款轮胎实测曲线（validation matrix 明示）。

### 6.3 整车时域动力学
- 简化动力学与多体（14 DOF）两模型对偶测试：巡航需驱动力矩抵阻力、升力高速卸载轮胎、toe/camber 加载主销但不偏航、坡度需求、满锁不发散。
- 载荷转移：横向/纵向平衡、低 μ 滑移增大、减速带 Fz 尖峰、斜坡减速（smoke）。

### 6.4 转向系统被控对象层（v2 核心，公式口径）
- **扭矩传感器只读弹簧项**（扭杆扭转），阻尼项不进助力映射——这是传感器物理的正确建模（`plant.py` docstring 明示）。
- **阻尼必须存在**：无阻尼时助力回路以 ζ=0.0036 发散，直到传感器饱和钉在 87°；生产 EPS 都带阻尼函数，此处增益按局部 boost 调度以保持回路阻尼比。
- **电机包络**：峰值转矩、空载转速（转矩到空载点线性归零）、反电动势限制、热降额（连续挪车 ×3 场景验证）。
- **齿条库仑摩擦 + 柔度**产生力矩-转角迟滞环；低握持力矩下小齿轮"卡住"（stiction 正确表现）。
- **峰值欠解析（重要数值发现）**：转向柱 DOF 引入 ~10 Hz 模态（握持刚度 vs 车轮惯量），内子步无法恢复、只有更细的**外步长**能捕捉。实测：

| dt | 峰值手力矩 | RMS |
|---|---:|---:|
| 5.0 ms（默认） | 1.864 | 1.214 |
| 2.0 ms | 2.472 | 1.267 |
| 1.0 ms | 2.700 | 1.289 |
| 0.5 ms | 2.812 | 1.299 |

RMS 跨十倍步长只动 7%（最后一次减半 <1%）；**峰值移动 51% 且仍在爬升——默认 5 ms 步长下峰值手力矩欠解析约 1/3**。测试钉住：`peak(coarse) < 0.8 * peak(fine)`（`test_steering_plant.py:252`）。**任何读峰值的指标（中心区试验、选型峰值转矩）必须用更细步长；读 RMS 的不必。**

### 6.5 ISO 13674-1 中心区指标（口径与拒绝规则）
- 指标：力矩梯度（角度域与 N·m/g 两种）、0.1 g 手力矩、迟滞环宽、角度死区、转向灵敏度、横摆相位滞后 + 实际达到的试验工况（幅值/频率）。
- 测量方法：过零点用相邻样本**线性插值**（50 Hz 记录率是必要条件）、迟滞环上下分支按转向速率分离、相位滞后用交叉谱法恢复已知滞后（0°/5°/15°/30° 参数化测试）。
- **工况错则拒绝**：无被控对象层、直线运行、非 weave、周期不足、>0.35 g——全部拒绝（§3.2）。这是本报告认为 v2 指标体系"严谨"的核心证据：**不给看着合理的数，也不在错误工况下给任何数。**

### 6.6 数值方法
- RK4 时域积分 + 前向欧拉位姿积分（离散化误差已量化：§4.3 的 cm 级轨迹误差、`pose_y` Δ≈0.017–0.019 m）；解析路径（准静态负载）与时域模型的偏差见 §9-D1。

## 10. 结论与迭代建议

### 10.1 结论

1. **质量门禁全绿**：777 单元 + 279 v2 专项 + 32 smoke + 5 黄金 + 2 benchmark（15 指标）+ 52 e2e + 完整发布门禁，全部通过。
2. **物理与数学可信度分层清晰**：运动学/转向几何达到解析级（1e-7 dps 偏差）；时域动力学有严格不变量与对偶验证但缺外部对照；转向被控对象层"默认关闭逐位不变"契约得到位级验证。
3. **v2 指标体系的设计严谨性值得延续**：错误工况拒绝、未评估不伪装通过、已知缺陷钉成测试、覆盖率一等输出——这是后续迭代应保持的标准。
4. **四条已知边界必须在迭代中被记住**：D1（解析路径偏差）、D3（边际带振荡）、D5（峰值欠解析）、D9（参数为估计值）。
