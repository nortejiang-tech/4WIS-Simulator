# v0.105.0 — 多点故障、动力学数值复核与 MCP 时间线（2026-11-13）

- 共享故障时间线支持最多 64 条、四轮同时或错时触发、持续或定时恢复；在仿真时刻边界切分积分，拒绝同轮冲突。实时 GUI、实验和隔离 Agent 使用同一实现。
- 机械卡滞锁定当前机构角，避免重复叠加静态前束；自由转向继承真实角速度、绕过电机伺服，按主销负载、惯量、隐式阻尼/库仑摩擦和非弹性止挡推进。物理故障拒绝运动学模型与不支持的共享齿条结构。
- 传感器偏差/噪声组合，掉线保持最后观测；固定种子，状态读取不推进随机序列。新增真实/上报角度、故障模式、角速度和实际事件导出。传感器注入仅影响观测，尚未接入控制器反馈。
- MCP `set_fault_schedule` 与 REST 原子设置支持 revision、request_id 幂等重试；既有单故障 REST 接口保留。
- 动力学子步上限 1.25 ms，保留转向植物跨外层周期的输入斜坡，内层积分不超过声明步长；数值失效暂停并记录错误，不自动重置伪装成正常运行。
- 新增四轮 × 八类 × 双模型故障测试、独立力/矩与角冲量断言、真实 MCP/GUI E2E、包内 MCP 冒烟与 Windows 原生 CI 资产。黄金数值随物理/积分修订更新，原容差与类别不变；修订原因及残余敏感性见数值复核报告。
- 提供同时、错时、四轮混合故障的双模型样例、离线 HTML、完整 gzip CSV/JSON 和数据校验和；当前仍无台架/实车/独立商业模型相关性证据。
