# v0.107.0 — full C++ backend

Release line: the sole canonical product release, built from the user's selected
full C++ backend route. The existing React browser UI remains. Built-in work
does not start the Python service; optional user Python/FMU/MATLAB plugins run
through an isolated compatibility worker.

## Included

- C++17 execution for built-in simulation state, controllers, steering, fault
  scheduling, recording, path planning, load/sizing/target analyses, studies,
  file storage, HTTP/WebSocket, and the 18-tool MCP service.
- Multi-point faults that can begin simultaneously or at separate simulation
  times, end or recover at configured times, and preserve exact event records.
- Mac Apple Silicon and Windows x64 portable ZIPs, a production React frontend,
  an optional plugin runtime, startup scripts, and MCP configuration helpers.
- Reproducible healthy, simultaneous-fault, and staggered-fault experiments;
  downloadable offline HTML analysis and raw JSON data.

## Verified

- C++ differential/domain/API/MCP tests: 238 passed on both Mac and Windows.
- Frontend: type-check and 54 unit tests passed on both platforms.
- Browser workflows: 58 passed on each platform.
- Portable archive checks: 10/10 on Mac and Windows; the Windows package also
  proves that the native extension loads its bundled MSVC runtime.
- Whole-experiment measurements on Apple M5 Pro / 64 GiB across eight cases:
  40.82–50.75× versus Python and 14.90–20.69× versus the kernel-only route.
  B measurements include process start, KPI work, and complete JSON output/read.

## Limits

Mac's C++ executable targets macOS 13.3 but was run here on macOS 27.2.1; older
OS runtime checks remain pending. Physical bench/vehicle correlation, actual
target-machine long-run GUI behavior, and licensed external FMU/MATLAB models
remain outside this release's software evidence. The full acceptance report
records the earlier Windows frame-timing failure and its unresolved cause.
