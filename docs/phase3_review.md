## A. 用户报告的 5 个问题 — 根因定位

### 1. 键盘无法定量控制车速/转角（松手归零）— 已复现根因
- `KeyboardInput.tsx` 松开 W/A/S/D 后 throttle/steering 以 τ≈0.25s 衰减回 0。
- 而 throttle 在所有策略里是**速度指令**（`v_cmd = v_max·throttle`），steering 是曲率/转角指令。
  所以松手 = 命令零速 + 回正。无法稳定巡航或保持定转角。
- **建议（M）**：增加"保持模式"开关。开启后：
  - W/S 改为**增/减目标车速**（步进，如 ±1 m/s），松手不归零 → 定速巡航；
  - A/D 改为**增/减目标转角/曲率**，松手保持 → 定转角；
  - 面板显示当前目标车速/转角，并提供"归零/急停"按钮。
  - 这是纯前端改动（不动后端契约），与现有"按住即给量"模式可切换。

### 2. 两次驾驶的路线 + 动态参数对比 — 功能缺失
- 当前 recorder 能导出单次 CSV，前端 `trajectory`/`history` 只存当前一次。
- **建议（M-L）**：A/B 双跑对比。
  - 后端已有 recorder 环形缓冲；增加"快照"端点：把当前一次跑的 trajectory + 选定通道存为命名 run。
  - 前端：录 run A → 重置 → 录 run B → 在 2D/3D 画布叠加两条轨迹（不同色），ChartPanel 叠加两条曲线。
  - 最小可用版本可纯前端实现：在 store 里保留"已固定的对比轨迹"快照数组，画布叠加渲染。

### 3. 离开对开路面后动态仍是低附 — 部分误解 + 真 bug
- **复现结论：μ 查询本身正确** —— 车轮离开区域后 `wheel_env` 立即恢复 base_mu（已验证）。**不是 μ 锁存 bug**。
- 真正的问题有三层：
  - **(a) 真 bug：`split_mu_demo.yaml` 缺 `model:` 字段 → 默认 kinematic**，而运动学模型完全忽略 μ。
    即这个"对开演示"项目根本演示不了对开。同样缺字段的还有 `default / compact_ev / delivery_robot`。
  - **(b) 残余动量错觉**：在低附区失控后（横摆/侧滑积累），离开区域时动量仍在，叠加问题①松手归零，
    看起来像"还在低附"。其实 μ 已恢复，是车身状态在收敛。
  - **(c) 无可视化反馈**：用户看不到每个轮的实时 μ，无法判断到底在不在低附。
- **建议**：
  - (S) 给 `split_mu_demo` 等项目补 `model: simplified_dynamic`，并在 smoke_test 加"对开演示项目必须用动力学模型"检查。
  - (M) HUD / 画布增加**每轮有效 μ 显示**（颜色或数字），低附时轮子标红 —— 一眼看清。
  - (M) 调查低附失控后的恢复（与 B 节动力学保真度一并处理）。

### 4. Slalom/DLC/单移线 地上无标志点，无法手动驾驶 — 步 17 已部分解决
- 步 17 的标准模块（slalom / double_lane_change / parking）**已自带地面桩 cones**，2D/3D 都渲染。
  生成后即可手动按桩驾驶 → 直接覆盖此需求。
- **遗留 gap**：`scripts_lib/` 里的动作脚本（slalom.yaml 等）是"自动执行"DSL，和"视觉桩布局"没有关联；
  加载脚本时地面不会出现对应的桩。
- **建议（S-M）**：把脚本工况与路径模板关联 —— 加载某脚本时自动生成对应模板（含桩）作为视觉参考；
  或在文档里说明"手动跑工况请用 轨迹/路径 面板生成模板"。

### 5. 减速带致停车、无 bump steer — 已复现根因（两个）
- **(a) fz 脉冲过大致数值不稳**：`SpeedBump.stiffness=1e6` × 高度 0.05 = **50 kN** 垂直脉冲。
  复现中 fz 瞬冲到 ~12 kN、轮速 ω 振荡发散；在某些速度/角度下会级联到怪异行为/近似停车。
- **(b) 架构上无法产生 bump steer**：当前是平面 3-DOF 模型，**无垂向/悬架行程 DOF、转向 δ=δ_cmd 刚性瞬时**。
  bump steer 来自悬架运动学（垂向行程→前束变化），本模型没有这个自由度，所以撞减速带只会改变 fz（影响附着上限+主销力矩诊断量），不可能产生转向扰动。
- **建议**：
  - (S) 把 fz 脉冲量级调合理并 clamp（如限制为静载的 2-3 倍），消除数值不稳。
  - (M) 加一个**简化 bump-steer 近似**：用垂向行程（ground_z）× `bump_steer_coeff` 给该轮 δ 叠加一个小扰动，
    让用户能直观看到"过坎跳一下"。作为可配置参数，物理上是工程近似。
  - (L/文档) 真实 bump steer 需要带悬架行程的多体模型（步 19）—— 文档写清当前限制。

## B. 广义技术审查（用户视角的其他问题/不足）

1. **动力学模型保真度偏低（重要）**：复现中，μ=0.9、constant steering=0.25、中速行驶时，
   理想阿克曼策略下 dynamic 模型出现 vy≈-7.8 m/s 的巨大侧滑并持续打转 —— 本应近似零侧滑。
   说明 `LinearTireModel` 刚度/`WheelSpeedServo` 增益/无转向速率限制三者耦合下，闭环很容易发散。
   与 smoke_test "kingpin τ 单调"未过、计划 §11 的 PI/载荷耦合是同一类问题。
   **建议（L）**：系统标定一轮 —— 轮胎侧偏刚度、servo Kp/Ki、加转向速率限幅 + 转向作动器一阶滞后（计划 §11 提到的 Phase 2.5）。

2. **kingpin τ_steer 非单调**（smoke_test 失败项，步 16-17 之前即存在）：
   steer 0→136、0.2→103、0.6→489 N·m，中段反降。疑似 KPI 居中项与 Fy 项符号/量级耦合。**(M) 待修**。

3. **策略-模型语义混用**：throttle 既当"速度"又当"油门"，在 dynamic 模型里经 servo 跟踪，
   语义不直观（踩满≠最大加速，而是目标满速）。**建议（S，文档）**澄清，或为 dynamic 模型提供"扭矩/油门"语义可选。

4. **3D 视图次要项未做**（步 16 范围内）：第一视角驾驶舱相机、悬架弹簧示意、模块拖拽放置、航点拖动微调。**(M) 可选补全**。

5. **录制内存**：计划 §8 风险表提过长录制内存涨；当前默认环形缓冲，超长录制建议落盘。**(M) 后续**。
