## 正确性修复（P0）

### D1：解析路径与时域模型解的是同一台车

`quasi_static_wheel_loads` 返回的载荷敏感 c_α 不带轴分配（0.80 前 / 1.20 后），
而时域模型按 `axle_cornering_scale` 以滑移角缩放——两条路径各实现一遍本构律，
必然各自漂移。实测稳态横摆偏差 −5% @30 km/h、−17% @60 km/h（幅值无关、随 v²
增长，因为它移动的是不足转向梯度 K）。

修复：本构律单源化为 `effective_cornering_stiffness`（载荷敏感 × 轴分配），
时域模型以滑移角缩放达到同值（Fy = −c_α·(s·α) ≡ −(s·c_α)·α），准静态路径直接
用缩放后的刚度。修复后对表误差 0.13% @30 / 1.10% @60 km/h。钉住缺陷的测试与
`with_axle_split` 开关已删除，代之以轴分配的回归钉。负载分析页与自行车增益
demo 显示值变化 5–17%——这是修复的证据，不是回归。历史研究报告不重跑。

### D5：峰值手力矩不再欠解析（转向层多速率）

指令在 5 ms 外步内零阶保持时，峰值手力矩 1.864 → 2.812 N·m（5 ms → 0.5 ms，
51% 且未收敛；RMS 只动 7%）。转向层现在以 **0.5 ms 内步率**运行（10×），指令在
步内**线性插值**（与前端 `renderPose.ts` 航位推算同理），车辆外环保持 5 ms，
输出在 5 ms 边界对齐回外环。0.5 ms 内步峰值与 0.25 ms 参考差 < 2%（实测一致）。
选型模块同步多速率化：`parking_hand_torque` 10.331 → 10.791 N·m（+4.5%，方向
"更真实"；判定不变）。黄金 5/5（转向层关闭）逐位不变；`test_disabled_plant_
changes_nothing` 位级契约保持。v2 黄金锚点按此重锁（迟滞环宽 −11.6%、死区
−5.9%、相位滞后 −4.8%——5 ms 指令阶梯的量化涂抹被消除）。

## 试验体系

### 摩擦的频域分离协议（C4）

0.2 Hz weave 下迟滞环宽对齿条库仑摩擦不单调的根因是车辆侧向动力学滞后。新
`procedures/friction_slow_ramp.yaml`（0.02 Hz、50 km/h）：动力学分量消失后环宽
对摩擦严格单调（0/80/260/900 N → 0.29/0.96/1.12/1.71 N·m）。`steering_feel@2→@3`：
迟滞环宽与死区**升为判定项**（判定工况 `freq_hz == 0.02`）。

### v2 黄金锚点 + 统一实验体系（S1/S2）

oncentre weave 的 10 个过程指标入黄金（容差按实测篡改探针标定）；两个 KPI 黄金
移植为 procedures 模板，黄金检查全部经 study runner 运行（KPI 逐位不变）；GUI
实验库孪生文件由 twin check 校验逐字段一致。

## 平台

### MCP 服务器（S3）

`sim4wis-mcp` 独立 stdio 进程（薄 HTTP 客户端、不 import sim4wis），8 个工具，
后端不在时自动拉起、退出只收自起的。验收流（spec → dry-run → run → 读报告）
含真实 stdio 握手端到端测试。

### 标定工作台立项（C3a）

`sim4wis calibrate residual` 一键产出残差报告：标准通道名读入（拼错即拒绝）→
同工况仿真 → 互相关对齐时钟 → 逐通道 RMS/峰值/RMS÷σ/相关 → 自包含 HTML（表 +
SVG 叠加图）。护栏：只输出残差，不自动改写参数库（拟合是 3.1b）。

### 渲染平滑性机器验证（H1）

3D 车顶视角拍频修复从人眼验证升级为 e2e 回归：注入 rAF 时间戳 → 脚本行车 →
帧间隔 40–300 ms 带内自相关 < 0.35。顺带修掉"GUI 开着脚本开不了车"（KeyboardInput
50 Hz 空闲推流覆盖脚本驾驶；现在脚本运行期间驾驶通道归脚本）。

## 已知边界（本版本如实声明）

- **0.2 Hz weave 的迟滞环宽对摩擦不单调**：摩擦要求在 0.02 Hz 慢斜坡上判定。
- **回正性仍缺"松手"工况**：`steering_feel` 该条报"未评估"（未评估就是未评估）。
- **参数仍为工程估计值（D9）**：趋势/架构对比/敏感度成立；绝对值定验收不成立。
  残差面板（C3a）是把它变成标定值的第一步，参数辨识（3.1b）未发货。
- **独立外部对照仍为 0（D8）**：v1 readiness 的 `independent_reference` 仍为 GAP，
  v1 宣称继续被 README 明示阻断；接入台架/外部工具数据后该门禁自转绿。
- 全量 pytest 唯一警告：StarletteDeprecationWarning（httpx → httpx2），随依赖升级处理。
