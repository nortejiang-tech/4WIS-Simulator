## 目标与约束

1. 实时、实验批跑和 Agent 共用故障时间线，以仿真秒为准，支持多轮同刻/错刻触发及可选结束时间；步内事件切分积分，半开区间 `[t_start,t_end)`。
2. 命令故障（归零、固定目标、限幅）保留执行器动态；机械卡滞锁住故障发生时的机构坐标；自由脚轮以轮胎主销力矩、惯量、阻尼、库仑摩擦和机械止挡求解，绕过正常电机伺服。
3. 物理卡滞/自由脚轮仅在受支持的独立转向动力学模型上运行；共享齿条等不支持的组合明确拒绝。K&C 与静态前束保留为机构之外的轮角贡献。
4. 同轮重叠执行器故障拒绝；跨轮可叠加；传感器偏差和噪声相加，掉线保持最后采样值。传感器故障目前只作用观测，不冒充闭环反馈故障。
5. 校验有限值、非负时刻/噪声/限幅与合法窗口；批量变更原子化。噪声受固定 seed 控制；读取状态不消耗随机数、不推进时间。
6. Agent 支持创建时带时间线及运行中带 revision/request_id 的原子设置；导出包含故障配置、实际事件和真实/上报轮角。

## 验收计划

- 基线与全量 pytest；故障时间边界、组合冲突、跨宿主一致、重试/陈旧 revision、MCP stdio E2E。
- 独立物理断言：质心 Newton–Euler 力/矩平衡、坐标变换、轮胎摩擦预算、非负支承载荷/守恒、轮速力矩平衡、主销虚功符号、自由脚轮耗散/止挡、卡滞无位置跳变。
- 故障类型 × 四轮 × 两个动力学模型覆盖；同时/错时/恢复组合；dt 敏感性；保留原有黄金工况。
- 前端类型/单测/生产 E2E；两平台便携包校验、Mac 原生启动、Windows runner 原生构建和启动验证。
- 样例报告由真实运行数据生成，包含配置、指标、图表、时间线、数值敏感性及可信度边界。
- GitHub 发布资产与 commit/tag 一致、校验和回读。
