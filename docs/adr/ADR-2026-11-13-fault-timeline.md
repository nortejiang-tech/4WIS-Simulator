# ADR — 统一故障时间线与独立转向物理边界

## Status

Accepted — 2026-11-13，v0.105.0。

## Context

v0.104.0 的实时 FaultInjector 只修改命令或序列化的传感器值；SimSession 另有五种时间故障。自由脚轮先积分再经过有源伺服，额外改变被动响应。噪声在读取/推送时采样，无法使不同宿主重放一致。同轮多个执行器故障按列表顺序覆盖。

## Decision

1. 共用受校验的 FaultSpec 与 FaultInjector，旧实时名称兼容归一化，新增字段使用默认值兼容旧实验。
2. 由共同 `advance_model` 在事件边界切分外层步长；动力学子步不超过 1.25 ms。外层保持普通命令，原详细转向植物的输入斜坡仍跨整个外层周期插值，不压缩到首子步。事件在仿真时钟上精确生效、结束；记录事件和采样语义。
3. 将物理覆盖作为明确的机构角约束传到动力学转向更新，避免绕经正常伺服。锁死与失电非自锁使用不同方程。自由转向使用隐式阻尼/库仑耗散步，止挡吸收向外速度。
4. 不定义矛盾机械状态的“优先级”：同轮重叠执行器故障拒绝。同轮不同观测故障有固定组合顺序。共享齿条的独立轮卡滞/失电不在当前模型内，拒绝运行。
5. 状态读取纯只读；传感器噪声在接受的积分步采样，seed 写入实验。Agent 的时间线修改延续现有 revision 与 request_id 契约。

## Rationale

修复一条共用力学链比维护三套近似逻辑更容易独立验收。保留车辆坐标、轮胎/主销简化、原有黄金工况；以解析不变量和收敛检查界定能力。没有实测参数时不扩展到不受约束的高保真宣称。

## Consequences

旧 free_caster 与含前束的 stuck_hold 结果会变化，报告必须注明版本。命令卡死名称保留兼容，但文档/界面明确为故障目标角，不能解释为瞬时位置跳变。自由转向采用固定车体基座的降阶主销 DOF 和上一接受步的道路力矩耦合；高频摆振、转向惯量对车体的反作用和三维主销轴需更高阶模型/实测对标。传感器故障只影响观测。物理正确性结论仅限已列方程和通过的验证范围。
