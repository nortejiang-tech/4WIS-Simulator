# 物理参考点、积分器与迁移边界

状态：本轮实施。日期：2026-09-08。关联：[评审 STAGE](../reports/STAGE_astra_review_2026-09-08.md)。

## 问题

API、项目、ICR 与轮心几何都以轴距中点 O 定义，平面动力学却使用质心 G 的牛顿欧拉方程。直接把公开原点改为 CG 会连带改变轨迹、历史 run、控制律、前端坐标和实验含义。旧轮速“半隐式”更新又用线性 Cκ 近似实际非线性轮胎，不能保持真实力律的平衡点。

## 决策

1. 保留 O 的公开坐标契约，集中到 `vehicle/rigid_body.py` 实现由 O 到 G 的速度、力矩和加速度变换。多体 heave/pitch 同样显式处理参考点质量耦合。
2. 车身与悬架保留现有 RK4，但 RHS 无副作用；准静态载荷只在接受一步后更新。轮速通过 `vehicle/wheel_dynamics.py` 求解真实轮胎力的后向欧拉方程。
3. 不声称整体四阶：轮速、载荷、K&C 和控制分步保持，整体存在一阶分裂误差。公开步长收敛数据，后续是否升级单体积分器由高频/低速接触需求决定。
4. 机构几何传力采用虚功雅可比 `ds/dδ`。旧 `geometry_efficiency` 字段保留为几何提示指标；功率效率仅作用于电机输入，避免改变 API 字段名造成兼容问题。不可达行程显式标识。
5. 驾驶参考限速与物理内核分离；显式实验速度不被驾驶辅助改写。原地旋转操作速率单独配置，界面声明纯滚动所需转角。
6. 原理说明共用 `physicsExplanations.ts`，削减公式复制引起的前端漂移。

## 替代方案与理由

全面切换外部多体引擎或改用 CG 公共状态会扩大迁移面，且缺少可验证其优势的实测参数。当前证据能支持针对性修正与窄重构；全面重写不能替代模型相关性验证。非线性轮速使用区间保护求根，无新增第三方依赖，保留当前轮胎插件接口。

## 后果与回滚

黄金指标会因力矩与力链修正改变，历史记录必须按版本区分。当前分支仅未提交 diff，可逐文件审阅撤销；用户初始工作树 clean，无 stash/reset/提交/发布。旧发行版、便携包、HTML 研究报告保留；本轮报告是新内核的证据入口。

通过内部测试不能证明实车精度。下一步需轮胎、K&C、主销空间硬点、执行器台架数据，以及独立工具或实车的匹配实验。
