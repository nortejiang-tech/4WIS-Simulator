# v0.106.0 — C++ 仿真内核迁移中间状态（仅过渡，不独立发布）

日期：2026-11-14。此状态位于 `codex/native-simulation-core`，基于 v0.105.0。完成路线比较后，用户选定全 C++ B 路线作为唯一正式产品线。A 只保留为每轮维护升级到全 C++ 的中间移植状态；本分支和早先 preview 包不再单独发布，旧 preview 资产仅作历史追溯。用户安装请使用 [v0.107.0 全 C++ 正式版](https://github.com/nortejiang-tech/4WIS-Simulator/releases/tag/v0.107.0)。

- C++17 执行平面及多体模型的 RK4、轮胎组合滑移力、非线性后向欧拉轮速求解、转向连杆约束与虚功雅可比。
- 保留 Python UI 服务、HTTP/WebSocket、MCP、控制器、故障时间线及所有既有文件格式。模型公式、步长、故障边界、求根收敛阈值不变。
- 保留 Python 数值参照。`SIM4WIS_ENGINE=python` 可直接回退；默认 `auto` 优先使用已安装 C++ 库。显式 `native` 缺少库时报错。自定义轮胎/模型钩子按 Python 执行并记录回退原因。
- Agent 能力、观察及实验/Agent 导出添加 `engine` 字段。Mac/Windows 包各自编译，携带原生库来源指纹；安装包测试要求实际 C++ 仿真与 MCP 调用成功。
- 新增新旧内核全通道轨迹对照、故障事件一致性、K&C/载荷/倒车/制动/详细转向、摩擦与角冲量、几何虚功和绑定缓冲区验证。
