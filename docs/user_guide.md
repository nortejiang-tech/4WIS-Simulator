# 4WIS Simulator — 用户使用说明（v0.3）

## 启动

在仓库根目录：

```bash
python3 scripts/start.py
```

脚本会自动：

1. 检测并安装后端 Python 依赖（首次启动需要几分钟，主要是 NumPy）
2. 检测并安装前端 Node 依赖（首次启动 `npm install`）
3. 启动后端 FastAPI（http://127.0.0.1:8010）
4. 启动 Vite 前端开发服务器（http://127.0.0.1:5173）
5. 自动打开浏览器

按 `Ctrl+C` 终止所有服务。

如果只想跑后端做端到端冒烟测试（不启动前端）：

```bash
python3 scripts/smoke_test.py
```

输出 `结果：28/28 通过` 表示仿真核心、三种模型、策略、扰动、脚本、录制等全部就绪。

> 也可用便携版（免装 Python/Node）：解压后双击 `start.command`（Mac）/`start.bat`（Win）。

## 键盘控制

| 按键 | 作用 |
|------|------|
| `W` | 前进（throttle → +1） |
| `S` | 后退 / 刹车（throttle → -1） |
| `A` | 向左转向（steering → +1） |
| `D` | 向右转向（steering → -1） |
| `Space` | 油门归零（coast） |
| `R` | 重置车辆位姿和轨迹 |
| `1` – `5` | 切换策略（顺序见侧栏） |

输入有平滑：按下 W 后，throttle 用一阶滞后曲线升到目标，时间常数 0.18 s。

**保持车速模式**（控制面板复选框）：开启后 W/S 增/减一个**持续的目标车速**，松手不减速；
`Space` 急停归零。适合远程/低延迟场景定速巡航。

**转向回正速度**（滑块）：控制松开 A/D 后车轮回正的快慢。最左 = `0 保持`（松手不回正，
方向锁定）；中间 ≈ 默认；最右 = `1.5× 最快`。

## 五种控制策略

| 策略 | 适用场景 | 关键特征 |
|------|----------|----------|
| **传统阿克曼** | 与传统车辆对照 | 仅前轮转向，后轮固定 δ=0；ICR 在后轴延长线上 |
| **理想阿克曼**（4WIS） | 转弯的标杆 | 四轮转角各自计算，**四轮瞬心严格共点**；零轮胎刮擦；ICR 在车体 Y 轴上（车身中线侧方） |
| **后轮转向** | 高速变道 / 紧凑转弯 | 后轮转角 = ratio × 前轮（默认 -0.5 反相）；ratio 通过 `mode_params.rear_ratio` 调整 |
| **蟹行** | 横向平移、平行停车 | 四轮同角度同方向；车身姿态不变，整体平移；ψ̇ = 0 |
| **零半径** | 原地掉头 | 四轮指向车辆中心；车辆绕几何中心旋转，位置不变 |

## 2D 可视化图例

| 元素 | 含义 |
|------|------|
| 蓝色车身矩形 | 车辆几何外形（含 0.3 m 前后悬） |
| 浅蓝色短箭头 | 车头方向（车体 +X 轴） |
| 深蓝色矩形 | 车轮（含真实转角） |
| 浅色短线 | 车轮滚动方向 |
| **黄色虚线** | 每个车轮的垂直线 —— 该轮的瞬心必须在这条线上 |
| **红色实心点** | 实际整车瞬心（由 vx, vy, ψ̇ 计算） |
| **蓝色虚线圈** | 策略指令的目标瞬心 |
| 青色曲线 | 历史轨迹（最近 4000 个点 ≈ 67 s @ 60 Hz） |
| 红色 / 绿色短线 | 世界原点的 +X / +Y 轴指示 |
| 灰色方格 | 1 m 网格（每 5 m 加重） |

**观察 4WIS 几何最直接的方法**：切到 `ideal_ackermann`，转向后看四条黄色虚线是否相交于同一点
（红色 ICR 应当与蓝色目标 ICR 圈重合）。然后切到 `ackermann`，四条线就**不再共点**，
后两条线（黄色后轮垂直线）总是水平的 —— 这就是传统阿克曼相对 4WIS 的几何劣势。

## 实时曲线

三组曲线在右侧底部：

1. **车速 vx 与横摆角速度 ψ̇**（颜色：青色 / 黄色）
2. **四轮转角 δ_FL / FR / RL / RR**（单位 °；颜色：蓝 / 紫 / 粉 / 绿）
3. **转向阻力矩 τ_FL / FR / RL / RR**（单位 N·m）

历史窗口保留约 30 秒（1800 个采样点 @ 60 Hz）。

> 注：Phase 1 的转向阻力矩为简化模型 `τ ≈ μ · F_z · scrub_radius · sign(δ) · min(|δ|/δ_max, 1)`，
> Phase 2 接入动力学后会用主销几何 + 实际侧向力计算。

## 项目文件（YAML）

项目文件存放在 `<repo>/projects/*.yaml`。每个文件包含：

```yaml
project:      # 名称与描述
vehicle:      # 几何 + 质量 + 转向限制 + 最大车速
suspension:   # 主销后倾 / 内倾 / 外倾 / 偏置（Phase 2 启用）
controller:   # 当前策略 + 策略私有参数
scene:        # 路面 / 扰动（Phase 2 启用）
recording:    # 录制的通道列表
```

### 内置示例项目

| 文件 | 用途 |
|------|------|
| `default.yaml`         | 中型轿车默认参数（L=2.8, m=1800 kg） |
| `compact_ev.yaml`      | 紧凑型 4WIS 电动车（L=2.5, 转向 ±45°） |
| `delivery_robot.yaml`  | 低速全向配送机器人（L=1.2, 转向 ±90°） |

### 操作

侧栏 **项目（YAML）** 面板：

- **加载**：选中下拉里的项目名 → 点 `加载`。后端会把该文件的参数应用到当前仿真器并复位位姿。
- **保存当前**：输入新名字 → 点 `保存当前`。当前车辆参数 + 当前策略会保存为 `<新名字>.yaml`。
  写入是原子的（临时文件 + `os.replace`），中途崩溃不会损坏既有项目。
- 项目目录可以通过环境变量 `SIM4WIS_PROJECTS_DIR` 重定向。

## 常见任务示例

### 1. 对比传统阿克曼 vs 理想阿克曼的几何差异

1. 启动后默认是 `ideal_ackermann`。按 `W` 加速到一定速度，按 `A` 持续左转 —— 注意：
   - 红点（actual ICR）始终在车体左侧、Y 轴附近
   - 四条黄色虚线相交于红点
2. 按 `1` 切到 `ackermann`（传统）。继续维持同样输入。注意：
   - 红点跑到车体左侧、X 轴 = -L/2 位置（后轴延长线）
   - 前轮两条黄线相交于红点，但后轮两条黄线是水平的，与前轮黄线在远处才相交
3. 比较轨迹（青线）：理想阿克曼的转弯半径明显更小

### 2. 验证零半径转向

1. 按 `5` 切到 `zero_radius`
2. 按 `W` 加速到一定油门
3. 注意所有四个车轮指向车辆中心；车辆位置几乎不动，但 HUD 里 `ψ` 在快速变化
4. 切回 `1`（阿克曼）按 `W` 起步 —— 立即可以看到差异

### 3. 蟹行入位

1. 按 `3` 切到 `crab`
2. 按 `W` —— 此时车辆笔直前进
3. 按住 `A`（同时不松 `W`）—— 车辆开始斜向左平移，车头朝向不变
4. 完全松开（自然回零）+ 反向按 `D` —— 体验蟹行的全向特性

### 4. 保存自定义参数为新项目

1. 加载 `compact_ev.yaml` 作为起点
2. 通过 `POST /api/params`（或日后的参数面板，Phase 2 加入）调整 wheelbase / 转向限制等
3. 在 **项目（YAML）** 面板里输入 `my_test`，点 `保存当前`
4. 文件出现在 `projects/my_test.yaml`

## 故障排除

| 现象 | 原因 / 处理 |
|------|------------|
| 右上角持续显示 `○ 未连接` | 后端没启动 — 检查终端是否报 ImportError；首次启动需要等 pip install |
| 浏览器打开后白屏 | Vite 还在编译 — 等 5-10 秒，刷新一次 |
| 切换策略后画面卡住 | 不应发生；如复现请 `R` 重置，并把控制台日志贴出来 |
| 曲线不更新 | WebSocket 断了 — 看 HUD 是否仍显示 `已连接`，否则刷新页面 |
| 项目加载 404 | YAML 文件不在 `projects/` 目录下，或文件名扩展名错 |

## Phase 2 新功能（已上线）

### 数据录制
侧栏 "数据录制" 面板：
- **● 开始录制 / ■ 停止录制** — 内部环形缓冲（默认 30 min）
- **导出 CSV** — 浏览器下载，文件名含时间戳
- 状态显示：采样数、时长、通道数

CSV 列结构见 `backend/src/sim4wis/recorder/buffer.py` 的 `AVAILABLE_CHANNELS`。

### 路面扰动
通过项目 YAML 配置：

| 类型 | 用途 |
|------|------|
| `ice_patch` | 冰面、湿滑路面（统一 μ 修正） |
| `split_mu` | 对开路面（左右 μ 不同） |
| `speed_bump` | 减速带（Fz 瞬态尖峰） |
| `slope` | 斜坡（重力纵向分量） |

详见 [disturbances.md](disturbances.md)。Canvas 上能直接看到色块。

### 动作脚本
侧栏 "动作脚本" 面板：
- 下拉选择内置脚本（slalom / DLC / crab_park / spin_demo）
- 点 "载入" → "▶ 启动脚本"
- 运行期间键盘输入被覆盖；停止后恢复键盘

详见 [scripting.md](scripting.md)。

### 车辆模型层级
项目 YAML 中：`vehicle.model: kinematic | simplified_dynamic`（默认 `kinematic`）。

主线模型：

- `kinematic`：纯几何/纯滚动模型，适合策略验证和 ICR 观察。
- `simplified_dynamic`：3-DOF 整车 + 轮胎力 + 载荷转移 + 转向负载，是工程分析、路面扰动和实时 KPI 的主线模型。

研究模型：

- `multibody`：14DOF 多体模型，保留给 `multibody_demo.yaml` 等高阶验证，不作为新功能默认适配目标。

切换到动力学后：
- 轮胎力来自 LinearTireModel（线性 + 摩擦圆裁断）
- Fz 包含静态分配 + 纵向/横向载荷转移 + 减速带瞬态
- τ_steer 用真实主销几何（scrub / caster / KPI）算出
- 滑移角 α 和滑移率 κ 实时可查

详见 [tire_model.md](tire_model.md)。

### Simulink 策略
算法同事的 Simulink 模型通过 FMU 或 MATLAB Engine 接入：

```
plugins/strategies/
├── my_strategy.fmu          ← Simulink Coder + FMI Kit 导出
└── my_strategy.fmu.yaml     ← 输入输出映射
```

启动时自动识别 → 出现在策略选择器里 → 像内置策略一样用。
详见 [fmu_integration.md](fmu_integration.md)。

## Phase 3 新功能（已上线 v0.3）

### 动力学模型三档切换
控制面板顶部「动力学模型」：**运动学 / 简化动力学 / 多体(14DOF)**。
- **多体**：6 车身 DOF + 4 悬架 + 4 车轮，有真实**侧倾/俯仰**（转弯外侧下沉、制动点头）、
  动态载荷转移、悬架行程驱动的 bump-steer；3D 视图里车身会随之倾斜。

### 3D 可视化
视口右上角 **2D / 3D** 切换。3D 里可用鼠标拖动旋转视角（OrbitControls），HUD 里可切「跟随/自由」相机。

### 轨迹 / 路径
「轨迹 / 路径」面板：选标准工况（绕桩/双移线/八字/停车…）点「生成」→ 地面出现参考线 + 桩；
点「跟踪此路径」切到 pure-pursuit 自动循迹。也可「手动绘制」在 2D 画布点击放航点。

### 路面摩擦
「路面摩擦」面板：下拉选预设（水泥 0.85 / 干沥青 / 雨天 / 雪面 / 冰面），或拖滑块手动微调基础 μ。
每个车轮的有效 μ 在 HUD 显示，低附时车轮标红。

### A/B 双跑对比
「双跑对比」面板：跑一遍点「存为 A」，再跑一遍「存为 B」→ 2D/3D 叠加两条轨迹，并画车速对比曲线。

### 主题
右上角 ☀/🌙 切换深色 / 浅色，记忆到本地。

### 视图朝向
2D 默认**前进方向朝屏幕上方**（不再是向右）。
